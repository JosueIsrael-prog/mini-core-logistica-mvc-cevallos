# Mini Core de Logística

Sistema de gestión logística construido con **.NET 8 (Web API)** y **React 19 (Vite)**.

## Estructura del Proyecto

```
MiniCoreLogistica-Cevallos/
├── Logistica.API/        # Backend - ASP.NET Core Web API (.NET 8)
├── Logistica.Client/     # Frontend - React 19 + Vite
├── MiniCoreLogistica.sln # Solución de .NET
├── global.json           # Fijación de versión del SDK
└── README.md
```
